Arquivos de instalação e atualização

Para a primeira instalação, utilize o instalador completo. Quando uma nova versão compatível for disponibilizada, usuários que já possuem o sistema instalado poderão utilizar o patch de atualização, que é significativamente menor. 

ams-install.exe   — instalação completa
AMS_Eye_Tracker_Patch.exe       — atualização de uma instalação existente

Importante: o patch não substitui o instalador completo em uma primeira instalação. Use o patch apenas quando já houver uma versão compatível do AMS Eye Tracker instalada no computador.

Passo a passo de instalação

Passo 1 — Instalar o AMS Eye Tracker

Execute ams-install.exe e siga as instruções na tela.

  • O instalador inclui os componentes necessários para execução offline; nenhum download adicional precisa ser realizado.
  • A instalação pode levar entre 5 e 15 minutos dependendo do computador.
  • Evite instalar em C:\Program Files\AMS Eye Tracker\ nesta versão, pois o Windows pode bloquear a gravação dos arquivos de calibração nessa pasta.

Recomendação de pasta: durante a instalação, escolha uma pasta com permissão de escrita, como C:\AMS_Eye_Tracker\. Não recomendamos copiar o executável para a Área de Trabalho depois de instalado; isso costuma deixar o computador desorganizado e pode dificultar suporte técnico.

Passo 2 — Executar o app

Abra o executável pelo atalho criado na área de trabalho ou pelo diretório de instalação.

  • Na primeira execução, o app pode demorar até 2 minutos para abrir enquanto inicializa os módulos de processamento paralelo e prepara os workers.
  • Nas execuções seguintes, a abertura será mais rápida.

Requisitos mínimos do sistema

ComponenteMínimo recomendado
Sistema operacionalWindows 10 ou Windows 11 (64-bit)
ProcessadorIntel Core i7 (8ª geração)/AMD Ryzen 7 equivalente ou Intel core i5 (11ª geração/série H)
Memória RAM8 GB
Placa de vídeoPlaca dedicada com driver atualizado
ArmazenamentoSSD com pelo menos 20 GB livres para instalação
InternetNão necessária (instalação 100% offline)

Nota de desempenho: lentidão durante preview e coleta pode depender de estabilidade da USB e do driver da placa de vídeo. Em computadores com GPU integrada, o processamento visual e a interface podem ficar mais lentos, mesmo com quantidade razoável de RAM.
